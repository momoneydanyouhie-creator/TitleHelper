# Curative Letter & Requirements Generator

A static website that drafts curative letters and requirements checklists for common title issues.
No build step, no dependencies. Open `index.html` locally to try it.

**Disclaimer:** drafts general language only. Not legal advice. Review before sending.

## Deploy
Push to GitHub, then connect the repo on Render as a Static Site (the included `render.yaml` configures it).

## Add or edit issues
Edit the `ISSUES` array near the bottom of `index.html`. Each issue has a name, a details label, a paragraph, and a list of requested items.
